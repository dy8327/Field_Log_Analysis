
# POS 로그 이상 탐지 도구

## 1. 프로젝트 개요

POS 또는 장비-서버 간 트랜잭션 로그를 분석하여  
정상 패턴과 다른 이상 데이터를 자동으로 탐지하는 로그 분석기입니다.

운영 중 발생할 수 있는 로그 오류를 사람이 직접 눈으로 찾는 대신,  
Python을 이용해 로그를 파싱하고 이상 유형을 분류하는 것을 목표로 합니다.

## 6. 기본 로그 구조 예시

```text
DEVICE001    PS CSTA=GGGXXXXXXXGGGXXXXXXX

SLOT01=92,5900,상품A SLOT02=79,5900,상품B SLOT03=86,5900,상품C

2022-05-31 오후 6:40:52    2022-05-31 오후 6:44:02    OK    POS_SERVICE/
````

현재 분석 대상 로그는 크게 다음 정보를 포함합니다.

| 구분    | 설명                 |
| ----- | ------------------ |
| 장비 ID | 로그를 발생시킨 장비 식별값    |
| 상태 코드 | 장비 또는 통신 상태 코드     |
| CSTA  | 장비 상태 또는 설정 관련 문자열 |
| 슬롯 정보 | 상품 위치, 재고, 가격, 상품명 |
| 시간 정보 | 로그 발생 또는 처리 시간     |
| 처리 결과 | OK / FAIL / ERROR  |
| 장비 타입 | 서비스 또는 장비 유형       |

## 8. 이상 유형 정의

현재 기준으로 탐지할 이상 유형은 다음과 같습니다.

| 이상 유형    | 예시                         | 판정      |
| -------- | -------------------------- | ------- |
| 깨진 문자    | `����`, `�`, 알 수 없는 특수문자   | 강한 이상   |
| 구분자 오염   | `//SLOT02`, `상품명//SLOT03`  | 주의 / 이상 |

| 필드 구조 깨짐 | `SLOT01=92,5900`           | 이상      |
| 슬롯 누락    | 기준 슬롯이 로그에서 빠짐             | 이상      |
| 결과값 누락   | `OK`, `POS_SERVICE/` 없음    | 이상      |

## 10. 트러블슈팅 기록

### 상품 슬롯이 0개로 파싱되는 문제

#### 문제 상황

정상 로그와 오류 로그를 비교했지만, 상품 슬롯 수가 0개로 출력되었다.

```text
상품 슬롯 수: 0
상세 비교 결과: 이상 없음
```

실제 오류 로그에는 가격 불일치와 비정상 구분자가 있었기 때문에
`이상 없음`이라는 결과는 잘못된 결과였다.

#### 원인

상품 슬롯을 추출하는 정규식에 불필요한 공백이 들어가 있었다.

문제 코드:

```python
products_pattern = r"(SLOT\d{2})=( \d+),(\d+),([^\s/]+)"
```

위 코드에서 두 번째 `\d+` 앞에 공백이 들어가 있었기 때문에
실제 로그 형식과 맞지 않았다.

실제 로그:

```text
SLOT01=92,5900,상품명
```

정규식이 찾던 잘못된 형식:

```text
SLOT01= 92,5900,상품명
```

#### 해결

불필요한 공백을 제거했다.

수정 코드:

```python
products_pattern = r"(SLOT\d{2})=(\d+),(\d+),([^\s/]+)"
```

#### 결과

상품 슬롯이 정상적으로 파싱되었고,
가격 불일치 및 비정상 구분자 오류를 탐지할 수 있게 되었다.

#### 배운 점

로그 분석에서는 정규식의 공백 하나로 전체 파싱 결과가 달라질 수 있다.

따라서 이상 탐지 결과가 이상하게 나올 경우,
비교 로직보다 먼저 다음 항목을 확인해야 한다.

* 정규식 패턴
* 실제 로그 형식
* 파싱된 데이터 개수
* 중간 출력 결과
* 정상 로그와 오류 로그의 구조 차이
